## Selected projects

- **[Kenlo Sites](https://www.rafaelst.dev/work/kenlo/)** — whitelabel real estate platform with 8,000+ active sites. Split a ~7MB JavaScript bundle into per-site chunks and served the ones common to all tenants from a CDN under a shared cache key, rebuilt the Redis caching around the reusable unit instead of the whole query, halved the build time, and shipped a React + TypeScript CMS and design system that became the standard for every new React project.
- **[Afindbar](https://www.afindbar.com/)** ([case study](https://www.rafaelst.dev/work/afindbar/)) — bar discovery app. Designed the Nest.js API and ingestion pipeline that keeps 1,000+ venues fresh through weekly queue-driven syncs, then built the React web app and the Expo mobile app. 1,000+ downloads on Google Play.
- **[Self-hosted infrastructure](https://www.rafaelst.dev/work/infrastructure/)** — three hosts running dozens of services: Coolify, Docker and Traefik, private behind Tailscale with one deliberately narrow public endpoint, and backups to three destinations.

More case studies at [rafaelst.dev/work](https://www.rafaelst.dev/work/).
